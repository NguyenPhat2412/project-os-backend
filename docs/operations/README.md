# Operations Documentation

Use this directory for local development, environment variables, Docker Compose,
release, deployment, health checks, backup, restore, and incident runbooks.

Current operational guidance applies to the modular monolith only. See
[`production-runbook.md`](production-runbook.md) for release, security,
backup/restore and incident-response controls, and
[`phase-0-operations.md`](phase-0-operations.md) for the detailed VPS
procedure. Legacy service-based deployment files are not supported.
